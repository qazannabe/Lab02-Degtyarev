«ПР2. Ответы на контрольные вопросы»
1. decimal для денег: double неточно хранит 0.1 и т.п. → ошибки в копейках. decimal точен

2. Переполнение byte: по умолчанию «заворачивается» (255+1→0). С checked — OverflowException

3. var: статическая типизация, тип выводится компилятором при компиляции и фиксируется. В Python — в рантайме, может меняться

4. Console.ReadLine() → всегда string (или null)

5. Parse бросает FormatException. TryParse возвращает false

6. false из TryParse → преобразовать не удалось; в out попадёт 0

7. TryParse — при вводе пользователя/файла/сети, где данные могут быть битыми и падать нельзя
